## FormFit monorepo

This repo contains two Next.js apps and shared packages:

- `apps/coach` — Coach Dashboard (`@formfit/coach`, port 3000)
- `apps/client` — Client Portal (`@formfit/client`, port 3001)
- `packages/ui` — shared UI primitives (`@formfit/ui`)
- `packages/shared` — domain models + localStorage helpers (`@formfit/shared`)

## This is NOT the Next.js you know

This version has breaking changes — APIs, conventions, and file structure may all differ from your training data. Read the relevant guide in each app's `node_modules/next/dist/docs/` (or the hoisted root `node_modules/next/dist/docs/`) before writing any code. Heed deprecation notices.
